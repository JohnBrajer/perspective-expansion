# Perspective Expansion

**John Brajer — Choseverse / Trillsverse framework**  
Formalized August 2026. Public version: 0.1.

## Principle

Before choosing among actions, change the model of the situation so that more possible actions become visible.

Decision quality can be constrained before evaluation even begins. If the visible action set is artificially narrow, a perfect ranking process can still select from a bad menu.

Perspective Expansion therefore separates two operations:

```
1. expand the recognized action space
2. evaluate the actions inside that expanded space
```

## Core question

> What becomes possible if the current framing is not treated as the boundary of the problem?

## Procedure

1. State the current model of the situation.
2. Identify which constraints are physical, legal, temporal, economic, social, psychological, conventional, or merely assumed.
3. Preserve real constraints.
4. Relax or re-express assumptions that are not actually governing.
5. Generate actions that were invisible under the original framing.
6. Only then evaluate, rank, or choose.

## Failure mode

A system that optimizes too early can become extremely efficient at choosing among unnecessarily limited options.

Perspective Expansion is designed to intervene **before** that compression.
